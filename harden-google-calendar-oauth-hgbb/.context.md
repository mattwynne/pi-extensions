# Goal
Make local OAuth authorization safe enough for reuse on multi-user machines and against callback injection.

# Priority
P0 — security release blocker.

# Definition of Done
- Credential/token material is created with restrictive permissions
- OAuth callback accepts only the locally initiated authorization flow
- Callback listener is loopback-only and cannot wait forever
- Automated tests cover the security-critical behavior

# Known Knowns
- Token writes currently inherit the process umask rather than explicitly using mode 0600
- The callback server currently does not explicitly bind to loopback
- No OAuth state value is generated or validated
- No timeout/cancellation cleanup exists
