# Goal
Expose the callback only on the local machine and always release listener resources.

# Priority
P0 — security release blocker.

# Definition of Done
- The HTTP server binds explicitly to a loopback address
- Authorization times out with an actionable message
- Success, OAuth error, invalid callback, timeout, and cancellation all close the server exactly once
- Browser-launch failure still leaves a usable, securely stored URL and a bounded flow
- Automated tests cover listener host and cleanup paths
