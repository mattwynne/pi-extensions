# Goal
Make only the reviewed, sanitized state reachable from the public GitHub repository.

# Priority
P0 — privacy release blocker.

# Definition of Done
- Rewrite public main into a single sanitized root commit after the final tree is ready
- Force-push only main; do not push old branches, tags, notes, or other refs
- No backup ref or preservation of the old commit history is required
- A reachability-aware secret/privacy scan of the exact ref intended for push passes
- The remote default branch points to the rewritten sanitized main

# Decision
Matt chose to discard the existing commit history: squash/rebase main to one sanitized root commit and force-push it. Preserving a private backup ref is unnecessary.
