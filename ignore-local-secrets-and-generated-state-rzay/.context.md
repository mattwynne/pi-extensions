# Goal
Prevent credentials, tokens, environment files, local state, and worktrees from being accidentally committed later.

# Priority
P0 — preventive security release blocker.

# Definition of Done
- Tracked .gitignore covers .env variants, OAuth client secrets, token directories, auth-url.txt, debug logs, private keys, .local state, .worktrees, and Yaks' .yaks projection
- Ignore patterns are narrow enough not to hide intentional examples or source fixtures
- Sanitized example configuration uses an explicit .example suffix and contains no real identifiers
- A test or release check verifies representative sensitive artefacts are ignored

# Known Knowns
- Current tracked .gitignore contains only node_modules/
- .worktrees is ignored today only through Matt's global gitignore and would not protect other clones
