# Goal
Reject OAuth callbacks that were not initiated by the active local authorization flow.

# Priority
P0 — security release blocker.

# Definition of Done
- Each authorization attempt generates a cryptographically random state value
- The same state is included in the Google authorization URL
- Missing or mismatched callback state is rejected before exchanging a code
- State values and authorization codes are never logged
- Automated tests cover valid, missing, and mismatched state
