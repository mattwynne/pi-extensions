# Goal
Give contributors and CI one deterministic command for release-critical checks.

# Priority
P1 — release reliability.

# Definition of Done
- Root package metadata declares Node 24+ and the MIT licence
- npm test/check scripts invoke all repository tests without hidden global dependencies
- Type checking or equivalent source validation covers every extension
- Calendar package audit is included without accidentally publishing either package to npm
- The command exits non-zero on any failed check
- README documents the command
