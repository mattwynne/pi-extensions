# Goal
Support multiple Google Calendar identities without hard-coded accounts or future cross-service architecture.

# Priority
P0 — required for reusable Calendar extension.

# Definition of Done
- The settings page can add, list, and remove multiple isolated Calendar accounts
- Verified account email is shown; internal storage identifiers remain hidden
- Adding an existing identity is rejected without mutation
- There is no default account or personal routing policy
- Calendar discovery spans accounts; all other operations identify account and calendar explicitly
- The Calendar-only Example Map passes as executable tests

# Deferred
Gmail, Docs, Drive, generalized Google identity, configurable scopes, and in-place re-authentication.
