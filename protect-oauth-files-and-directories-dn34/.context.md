# Goal
Prevent other local users from reading OAuth credentials, refresh tokens, authorization URLs, or debug data.

# Priority
P0 — security release blocker.

# Definition of Done
- ~/.pi/google-calendar and its token directory are created with mode 0700
- client/token/auth URL writes use mode 0600 and preserve restrictive permissions on refresh
- Debug output cannot disclose authorization codes, tokens, or credential values
- Automated tests verify requested file modes and non-disclosure
