# Goal
Make the extension's background model calls, cost, and session-data transmission intentional and transparent.

# Priority
P1 — privacy, cost, and product-expectation requirement.

# Definition of Done
- README states when naming calls happen, which selected model/credential is used, and how much session context may be sent
- Default behavior follows Matt's explicit policy decision
- Users can disable periodic calls without editing source
- No naming request includes tool secrets or more context than documented
- Tests cover initial, manual, periodic, disabled, and unchanged-session behavior

# Known Knowns
- Current behavior may make a model request every five minutes after session changes
- A request may include up to 6,000 characters of session context
- These calls can incur cost and transmit material users did not expect to resend

# Known Unknowns
- Whether periodic renaming should be default-on, opt-in, or removed
