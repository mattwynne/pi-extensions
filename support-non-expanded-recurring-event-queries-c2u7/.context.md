# Goal
Send a valid Google Calendar events.list request when callers ask not to expand recurring events.

# Priority
P1 — correctness.

# Definition of Done
- orderBy=startTime is sent only when singleEvents is true
- singleEvents=false returns recurring series without an unsupported parameter combination
- Ordering semantics are documented for both modes
- Tests assert exact API request parameters for true, false, and omitted singleEvents

# Known Knowns
- Current code always sends orderBy=startTime, which Google rejects when singleEvents=false
