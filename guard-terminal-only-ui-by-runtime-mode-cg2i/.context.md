# Goal
Keep question and session-title extensions functional across Pi TUI, RPC, JSON, and print modes.

# Priority
P1 — compatibility.

# Definition of Done
- Custom terminal components and editor replacement run only when ctx.mode === "tui"
- RPC uses only UI interactions supported by the RPC Extension UI protocol or a defined fallback
- JSON and print modes do not attempt UI rendering
- Tests cover mode behavior for extensions/question.ts and extensions/session-title/index.ts

# Known Knowns
- Both extensions currently check ctx.hasUI, but RPC may have UI without supporting custom terminal components
- Pi documentation requires ctx.mode === "tui" for terminal-only behavior
