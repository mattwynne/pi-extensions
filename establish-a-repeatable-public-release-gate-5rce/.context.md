# Goal
Turn “safe to publish” into a command-driven, repeatable decision rather than a one-off manual judgment.

# Priority
P1 — required before public release.

# Definition of Done
- One documented command runs the repository's automated release checks
- Tests cover every corrected P0/P1 behavior
- Dependency vulnerability checks pass
- Secret/privacy scanning covers the exact refs intended for push
- The clean public root commit is tested after creation
- Final release checklist records repository visibility, branch/ref scope, and scan results

# Known Knowns
- Current 7 tests cover only automatic session naming and provider selection
- Calendar and TUI extensions currently lack tests
- There is no root package.json or CI workflow

# Known Unknowns
- Whether checks should run only locally or in GitHub Actions as well
