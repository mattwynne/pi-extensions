# Goal
Make the repository legally clear to copy, modify, and redistribute.

# Priority
P0 — public release blocker.

# Definition of Done
- A root repository licence exists
- The Google Calendar package metadata uses a compatible licence
- The Pi-derived question extension preserves the upstream MIT copyright and permission notice
- README states the project licence and any third-party attribution location

- extensions/google-calendar/package.json declares ISC but includes no ISC licence text
- extensions/question.ts is substantially derived from Pi's MIT-licensed official example
- Permissive dependency licences were found; no apparent copyleft conflict
