# Goal
Ensure the public repository does not expose personal account addresses, organization affiliations, private cloud project names, or machine-specific checkout assumptions.

# Priority
P0 — privacy and reusable-product release blocker.

# Definition of Done
- Calendar accounts come from user-owned configuration rather than source code
- Documentation and prompt text are generic and path-neutral
- Private Google Cloud project identifiers are absent
- Publicly reachable git history contains none of the removed identifiers
- A history-aware rescan reports no personal account details or private infrastructure identifiers

# Known Knowns
- Historical source and documentation contained personal/work addresses
- Historical Calendar setup documentation named a private Google Cloud project
- Installation examples use an author-specific checkout path
- Commit author identity is expected for a personal GitHub repository and is not itself treated as a leak

# Decision
Discard the existing public-main history and force-push one sanitized root commit.
