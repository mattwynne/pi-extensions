# Goal
Avoid recurring background model calls unless a user deliberately enables them.

# Priority
P1 — privacy and cost behavior.

# Definition of Done
- Initial naming and explicit /auto-name-session remain available by default
- Five-minute renaming is disabled by default
- A non-secret setting enables periodic renaming and documents its interval/context implications
- README discloses selected-model use, maximum context sent, and potential cost
- Tests prove disabled-by-default, opt-in periodic, unchanged-session suppression, and manual behavior
