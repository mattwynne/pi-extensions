# Goal
Verify the exact commit and refs intended for GitHub contain no credentials, personal identifiers, unsafe configuration, or unintended history.

# Priority
P0 — final release gate.

# Definition of Done
- Release checks pass on the clean public root commit
- Secret scanning covers tracked files and every object reachable from refs that will be pushed
- Personal email addresses, organization identifiers, cloud project names, private URLs, local paths, and credential artefacts are absent
- Only the intended main branch is pushed; no private backup refs, old branches, or tags are included
- A human-readable checklist records commands and results
- Publication remains a separate explicit action after review
